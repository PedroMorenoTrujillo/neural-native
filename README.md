# Neural Native

**Native Angular components for iOS and Android.**

Neural Native brings the Neural visual language to [Angular Native](https://ng-native.com): 64 mobile component entries, Angular signals, typed APIs, shared themes and modular imports.

**Next beta: `0.1.0-beta.3` (not yet published).** APIs and framework compatibility may change before 1.0. Pin the version in your application lockfile and check compatibility before updating Angular Native.

## Install

Start with the compatible Angular Native template:

```sh
npx create-expo-app@latest my-neural-app --template @ng-native/template@0.19.1
cd my-neural-app
npm install @neural-ui/native@beta
```

This branch prepares compatibility with Angular Native 0.19.1. Wait for Neural Native 0.1.0-beta.3 to be published before using the installation commands above: the current npm beta.2 requires Angular Native 0.18.2. Releases use the npm `beta` tag; `@beta` is intentional.

Angular Native connects Angular to the native renderer. Application components use Angular templates and signals; they do not require React components or a WebView. See the [framework setup guide](https://ng-native.com/guide/getting-started).

## Your first screen

Replace `src/app/app.ts` in the generated application. Keep the exported class name `App`: the generated entry point already mounts it.

```ts
import { Component, signal } from '@angular/core';
import { SafeAreaProvider, SafeAreaView, Text, View } from '@ng-native/components';
import { NeuThemeComponent } from '@neural-ui/native/theme';
import { NeuInputComponent } from '@neural-ui/native/input';
import { NeuButtonComponent } from '@neural-ui/native/button';

@Component({
  selector: 'app-root',
  imports: [
    SafeAreaProvider, SafeAreaView, Text, View,
    NeuThemeComponent, NeuInputComponent, NeuButtonComponent,
  ],
  template: `
    <safe-area-provider>
      <neu-theme scheme="system">
        <safe-area-view class="screen">
          <view class="content">
            <neu-input label="Full name" [(value)]="name" />
            <neu-button label="Save profile" (pressed)="save()" />
            <text class="feedback">{{ feedback() }}</text>
          </view>
        </safe-area-view>
      </neu-theme>
    </safe-area-provider>
  `,
  styles: `
    :host, .screen { flex: 1; }
    .content { padding: 24px; gap: 16px; }
    .feedback { color: var(--neu-text); }
  `,
})
export class App {
  readonly name = signal('');
  readonly feedback = signal('');

  save(): void {
    const name = this.name().trim();
    this.feedback.set(name ? 'Saved: ' + name : 'Enter your name.');
  }
}
```

Run the application's generated `npm start` command, then open Android, iOS or a compatible Expo Go host. The example keeps its state in memory; connect your own service for persistence.

## State and forms

The application owns editable data and actions:

- `[(value)]="name"` connects a writable signal to a text control.
- `[(checked)]="enabled"` connects Checkbox or Switch.
- `[disabled]="saving()"` configures a control.
- `(pressed)="save()"` requests an application action.
- `[(open)]="editing"` controls a presentation.

Angular Signal Forms is optional. Import `FormField` from `@angular/forms/signals` and bind `[formField]` to a field in your form tree instead of maintaining a second value signal. Keep `@angular/forms` aligned with the application's Angular version.

## Themes and customization

Place one `neu-theme` around the application. Descendant controls inherit it. `scheme` accepts `system`, `light` or `dark`; `tokens` accepts `Partial<NeuTokens>`. Add the following type import and property to your root component.

```ts
import type { NeuTokens } from '@neural-ui/native/foundation';

readonly brand = {
  accent: '#3B5BDB',
  onAccent: '#FFFFFF',
  radius: 16,
} satisfies Partial<NeuTokens>;
```

Bind that property with `<neu-theme scheme="system" [tokens]="brand">`. Use `--neu-*` variables in native styles to share the resolved palette and scale. A fixed token override applies in both light and dark modes: provide mode-specific values when your brand needs them.

Use projected content with controls such as Card, Modal and Bottom Sheet. Collection components expose typed customization APIs; check each component's public inputs before supplying a template.

## Accessibility and localization

Provide visible labels, useful validation messages and accessible names for icon actions. Localize the labels exposed by the component API; date controls also accept `locale`. Translate display labels while keeping option IDs and saved values stable.

Neural Form Field arranges projected content; connect the name, requirement and help to the projected native control itself. It is separate from Angular Signal Forms' `FormField`.

Check the complete application with VoiceOver/TalkBack, enlarged text, reduced motion, keyboard input and both orientations. Native controls and custom themes need verification in the application where they are used.

## Development

```sh
npm ci
npm run build
npm run typecheck
npm run lint
npm test
npm run test:showcase
npm run verify:consumer
```

`verify:consumer` installs the packed library in an isolated application, checks templates and interactions, and creates iOS and Android bundles. To explore the native catalogue, run `npm run showcase` and open it with a compatible native host.

Generated build, coverage and verification outputs are ignored by Git and are not included in the npm package.
